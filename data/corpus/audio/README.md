# Recordings

Only recordings with a signed consent form (`CONSENTIMENTO.md` (this folder)) go here. Keep the signed forms **outside** the repository.

Naming: `<speaker-code>-<island>-<NN>.ogg`, e.g. `S03-santiago-02.ogg`, one row per file in `metadados.csv`. The speaker code is an anonymous label; the mapping to real names stays offline.

What to ask for: orders as people would really send them, not read scripts. Include negations ("não, não é esse"), corrections ("afinal…"), and vague references ("kel otu", "o mesmo de ontem").

Target: 15–20 recordings from 5–6 speakers, mostly Santiago, some São Vicente.
